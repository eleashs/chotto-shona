# ছোট্ট সোনা – বেবি শপ

বেবি প্রোডাক্টের অনলাইন শপ (ডেমো)। বাংলা ও ইংরেজি ভাষা, কার্ট, কুপন, চেকআউট (COD / bKash / Nagad), ইউজার ও অ্যাডমিন লগইন, রিটার্ন পলিসি।

## GitHub Pages-এ লাইভ করার নিয়ম
1. GitHub-এ নতুন repository খুলুন (যেমন `chotto-shona`), Public রাখুন।
2. `index.html` ও `README.md` আপলোড করুন (Add file → Upload files → Commit)।
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save।
4. ১-২ মিনিট পর লিংক পাবেন: `https://<আপনার-username>.github.io/chotto-shona/`
